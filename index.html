Manual prático de comandos de CMD e Executar para manutenção, otimização e limpeza profissional do Windows.

CMD Admin

Reparação de Arquivos de Sistema

Varre todos os arquivos protegidos do Windows e substitui as cópias corrompidas pelas originais em cache.

sfc /scannow
Orientação: Execute sempre no Prompt de Comando como Administrador. Se indicar "reparo pendente", reinicie o computador antes de tentar novamente.
CMD Admin

Reparo de Imagem do Windows (DISM)

Restaura a imagem base dos componentes do Windows através do Windows Update quando o SFC falha.

dism /online /cleanup-image /restorehealth
Orientação: Requer conexão com a Internet. Execute antes do sfc /scannow se o sistema estiver com graves instabilidades.
CMD Admin

Remover Fila de Reparos Pendentes

Cancela atualizações e operações de reparo pendentes que bloqueiam outros utilitários de diagnóstico.

dism /online /cleanup-image /revertpendingactions
Orientação: Útil quando o computador fica preso em "reparo de sistema pendente" após atualizações interrompidas. Reinicie em seguida.
Win + R

Arquivos Temporários do Usuário

Abre a pasta com os arquivos temporários gerados pelos aplicativos da conta atual.

%temp%
Orientação: Pressione Ctrl + A para selecionar tudo e Shift + Delete para apagar de forma permanente. Ignore arquivos em uso.
Win + R

Arquivos Temporários do Sistema

Abre a pasta de arquivos temporários raiz do sistema operacional Windows.

temp
Orientação: Apague o conteúdo periodicamente para liberar espaço no SSD/HD principal.
Win + R

Cache de Pré-carregamento (Prefetch)

Armazena dados de inicialização de aplicativos. Limpar ajuda quando há erros na execução de softwares.

prefetch
Orientação: Requer permissão de administrador ao abrir. Pode apagar todo o conteúdo com segurança.
Win + R

Limpeza de Disco Avançada

Abre o assistente nativo do Windows para remover atualizações antigas, dumps de memória e lixeira.

cleanmgr
Orientação: Clique em "Limpar arquivos do sistema" dentro da ferramenta para remover gigabytes de atualizações antigas do Windows.
CMD Admin

Renovar Cache DNS

Limpa o cache de resolução de nomes DNS para corrigir sites que não carregam ou abrem com endereço antigo.

ipconfig /flushdns
Orientação: Essencial em atendimentos remotos quando o cliente relata lentidão de navegação ou sites não carregando.
Win + R

Configuração do Sistema (MSConfig)

Acessa as definições de inicialização, serviços e opções de boot do sistema.

msconfig
Orientação: Na aba "Serviços", marque "Ocultar todos os serviços Microsoft" antes de desativar qualquer item desnecessário.

Etapa 01 — Primordial

Triagem Inicial & Diagnóstico do Hardware

Antes de alterar qualquer configuração de software, entenda o estado do hardware da máquina do cliente.

  • Verificar Armazenamento: Confira em "Este Computador" se o disco (C:) é SSD ou HD mecânico e o espaço livre (menos de 10% livre causa lentidão extrema).
  • Verificar Memória RAM & CPU: Abra o Gerenciador de Tarefas com Ctrl + Shift + Esc e analise o uso de CPU, RAM e Disco em repouso.
  • Saúde do Disco (S.M.A.R.T.): Se o disco estiver em 100% constante, verifique a saúde com uma ferramenta leve como o CrystalDiskInfo. Não adianta otimizar o software se o disco estiver danificado.
💡 Dica do Técnico: Se o cliente usa HD mecânico como disco do sistema, recomende a migração para SSD como prioridade máxima de upgrade.
Etapa 02 — Inicialização & Processos

Limpeza de Inicialização (Boot Limpo)

Softwares em segundo plano são a causa nº 1 de lentidão após ligar o sistema.

  • Aplicativos de Inicialização: No Gerenciador de Tarefas, aba "Aplicativos de inicialização", desative programas pesados que não precisam abrir com o Windows (ex.: Spotify, Steam, Discord, Teams).
  • Serviços de Terceiros: Execute msconfig, vá em "Serviços", marque obrigatoriamente "Ocultar todos os serviços Microsoft" e desative atualizadores desnecessários (ex.: Adobe, Google Update).
Etapa 03 — Limpeza de Arquivos Residuais

Liberação de Espaço e Arquivos Temporários

Remova gigabytes de lixo eletrônico que sobrecarregam o índice de busca e o disco.

  • Pastas Temporárias: Acesse via Win + R as pastas %temp%, temp e prefetch e elimine os dados antigos.
  • Limpeza de Disco Integrada: Execute cleanmgr como administrador para remover itens da lixeira, relatórios de erro e cópias antigas do Windows Update.
Etapa 04 — Integridade do Sistema

Verificação e Correção de Sistema Corrompido

Garanta que o sistema operacional está estável antes de finalizar o atendimento.

  • Reparo de Imagem: Se houver falhas recorrentes, rode dism /online /cleanup-image /restorehealth no CMD como administrador.
  • Verificação de Integridade: Execute sfc /scannow no CMD como administrador para corrigir DLLs e arquivos danificados.
  • Rede e Navegação: Execute ipconfig /flushdns para limpar o cache DNS e evitar lentidão no navegador.
Etapa 05 — Validação & Encerramento

Reboot e Teste Final

Confirme a melhoria e entregue a máquina pronta ao cliente.

  • Reinicialização Completa: Reinicie o sistema para consolidar os arquivos reparados e as alterações feitas.
  • Validação dos Resultados: Abra o Gerenciador de Tarefas e confirme se o uso de CPU, RAM e Disco baixou em repouso.
  • Relatório ao Cliente: Informe brevemente as ações realizadas (arquivos limpos, inicialização otimizada e correções de sistema).
